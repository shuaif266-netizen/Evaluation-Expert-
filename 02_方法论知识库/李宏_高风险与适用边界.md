# 高风险问题与方法适用边界

## 高风险表述检查

评审时重点扫描：

- 空泛宏大表述或政策口号替代学术论证；
- 没有明确检索依据的“首次、首创、尚无研究、填补空白”；
- 结论强度超出研究方法和证据能力；
- 核心概念未定义、不同章节含义变化或只在题目出现；
- 创新、方法、目标或成果突然增加正文没有承担的任务；
- 预期结论被写成已有事实；
- 对政策、数据、文献、项目获批情况作没有来源的断言。

**依据与等级**：高风险词本身不自动构成缺陷；应结合申请书上下文判定。此清单为本系统 C 类评审规则，受用户本轮任务中“不得编造事实、政策、数据、观点”的要求约束。

## 材料使用边界

1. H1 是经济学领域申请书样本。仅使用章节功能、论证关系、任务组织、研究方法如何服务问题、前期基础如何支撑任务等结构信息。
2. H1 和 H2 中具体经济学事实、概念、理论、模型、指标、数据和政策结论均忽略，不进入跨学科知识库或评审案例。
3. H3 是研究方法课件，可引用其关于研究设计、资料收集—分析—解释、证据支撑和修正判断的明确表述。
4. 李宏范式_可借鉴与不可照搬清单.md 是另一艺术教育课题的材料，不当作李宏教授观点或本项目通用方法证据。
5. 申请书样本的项目申请类别和文本格式具有年份限制；正式评审前必须查验当年通知和申请模板。
6. 目前仅有一份直接申请书样本和一个相关前期项目案例，且彼此来自同一研究主题，不能据此验证跨领域普遍规律。

## 系统风险

- **样本偏少**：规则可能贴合单个样本。
- **学科偏差**：核心申请书来自经济学；本系统必须按申请书所属学科重新判断方法规范。
- **结果未知**：H1 未提供该份 2020 申请的最终评审或立项结果。
- **时间偏差**：早年申报格式和政策背景不能代替当年正式要求。
- **提炼偏差**：B/C 级归纳可能过度一般化，需持续用跨学科案例校准。
- **评审倾向**：强调找失败理由可能过严；每项批评应写反证条件、来源和根因。
