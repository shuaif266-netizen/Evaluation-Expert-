# 原写作 Skill 改进建议

本文件只提出证据对照建议，不直接修改根目录 SKILL.md 或其规范副本。执行任何 Skill 内容修改前，需由用户确认。

## 建议 1：校准样本质量与立项状态表述

**原规则**：Skill 元数据称其从“高质量国家社科项目申请书”抽象，来源是《国家社科基金项目申请书（李宏）》。

**原始材料**：H1 第 1 页显示一份 2020 年国家社科基金重点项目申请书；文件未显示该份申请最终立项结果。H1 第 13—14 页确认的是另一个 2015 年重点项目已结项，不能证明 2020 申请获批。

**差异**：当前目录材料可以支持“申请书样本”判断，不能独立支持对该份申请的结果性质量或获批状态判断。

**建议**：若没有独立的官方立项记录，将“高质量 / 获批样本”改成“国家社科基金申请书样本”；在样本索引中单列项目年份、申报类别、评审结果是否已核实。

**风险**：未来若补充官方立项记录，应更新样本状态；过度降格也可能低估其可借鉴价值，因此区分“结构样本价值”和“资助结果证据”。

## 建议 2：明确写作和评审两种任务边界

**原规则**：Skill 同时用于总控、段落起草、结构校验与压力测试，调用方式称其为写作与审查的“最高写作逻辑规则”。

**原始材料**：H2 展示申报写作栏目；H3 聚焦研究过程、证据和论文表达。两者支持研究设计逻辑，不等同于同行评审的反向否证和问题分级流程。

**差异**：作者写作和评审诊断的工作目标不同；原 Skill 没有稳定的评审报告格式、证据标准和 S/A/B/C 级别。

**建议**：保留原 Skill 的写作用途，评审转由独立的 nssfc-proposal-reviewer 承担；需要共用时只引用逻辑映射规则。

**风险**：双 Skill 可能导致用户误用。以 AGENTS.md 明确触发条件，并在 reviewer references 中指明边界。

## 建议 3：把固定内容顺序改成待检验结构，不作为唯一模板

**原规则**：Skill 推荐“事实 / 发生识别 → 关系 / 影响解释 → 机制 / 形成解释 → 路径 / 策略转化”等递进内容结构。

**原始材料**：H2 第 7—8 页案例使用事实、机制、风险、政策等层次；H1 第 6—10 页采用相近结构。

**差异**：这证明一种申请书案例结构，但没有证明定性、规范、历史、比较或其他学科研究都必须如此排序。

**建议**：保留为可选结构示例；写明需根据核心问题、学科范式与证据路径判断各任务关系，不机械要求四阶段递进。

**风险**：若只强调灵活，可能弱化内容接口审查；仍要要求申请人解释并证明自己的排序。

## 建议 4：加强概念操作化与结论强度检查

**原规则**：已有 Skill 要求概念、方法、证据和研究问题相互服务，并提示方法不能支持过强结论。

**原始材料**：H1 第 6 页对其研究核心概念作定义并提出测度设计；H1 第 9 页罗列研究方法。它是经济学写法实例，不是其他学科的指标指南。

**差异**：原 Skill 仍未将“概念如何被观察 / 分析”和“方法实际允许何种推论”写成强制审查字段。

**建议**：在 reviewer Skill 和逻辑清单中增加定义、边界、操作化、材料质量、分析步骤、替代解释、结论边界检查；按学科规范决定适用方式。

**风险**：若把操作化只理解为量化指标，会误伤解释性或规范性研究；措辞须覆盖适合该学科的观察与论证方式。

## 建议 5：创新标签必须接受相对比较

**原规则**：Skill 已区分创新类型，强调创新要由缺口、内容和方法推出。

**原始材料**：H2 第 15 页和 H1 第 10 页使用“新视角 / 新思想 / 新策略 / 新观点”等类别。

**差异**：材料中的类别便于组织文本，但类别本身不能证明相对既有研究存在知识增量。

**建议**：评审规则要求明确对照对象、差异、增量及其证据来源；类别只作表达组织，不作创新判断结论。

**风险**：文献覆盖不全时，评审人也可能误判“并非创新”；报告应限定检索证据，并区分“申请书尚未证明”与“领域不存在”。

## 建议 6：把竞争性审查、跨章节冲突和反向否证作为独立评审流程

**原规则**：原 Skill 有 30 秒压力测试和栏目映射，但主要帮助作者补全写作闭环。

**原始材料**：H1/H2 展示研究设计组织；H3 提醒根据证据修正预判。材料没有构成系统的资助竞争评审流程。

**差异**：原 Skill 不要求形成不资助理由、证据回应、S/A/B/C 等级或跨章节冲突标签。

**建议**：按独立 Reviewer Skill 执行，不回写覆盖原写作 Skill。

**风险**：反向否证可能变成无依据挑刺；每条反对理由必须引用申请书证据，并说明什么新证据会改变判断。
