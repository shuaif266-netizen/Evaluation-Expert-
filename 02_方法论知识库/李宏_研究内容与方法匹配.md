# 研究内容与研究方法匹配

## 原则

每个研究内容要说明它回答什么问题、分析什么材料、使用什么方法、得到什么可支持的认识，以及与其他内容的关系。

## 为什么

“采用某某法”只给出方法名称，没有说明研究如何发生。方法与问题不匹配时，后面的结论即使表达完整也可能无法从证据推出。

## 适用场景

研究内容、总体框架、研究方法、研究计划、可行性、重点难点与预期成果审查。

## 判断问题

- 每个研究内容回答哪个问题？
- 前后任务是递进、并列、比较、分类还是条件关系？
- 需要什么材料 / 样本 / 档案 / 文本？从哪里获得？
- 方法有哪些实际分析步骤？其结论能力到哪里为止？
- 研究计划、团队分工和条件能否覆盖这些步骤？
- 若关键资料不可得，有何替代材料或结论收缩方案？

## 研究方法的最小说明单元

建议逐项补清：研究问题 → 分析对象与材料 → 方法步骤 → 判断依据 → 可支持结论 → 局限。此框架是本系统 C 类评审工具，不是李宏教授原文表述。

## 正面与反面示意

- **正面模式**：方法章节明确说明每个方法对应哪项任务、如何执行、形成什么证据、能支持多强的结论。此为 C 类示意。
- **反面模式**：列出多个方法名词，却未交代样本、分析动作或任何问题—方法对应。此为 C 类示意。

## 评审追问

- 这个方法具体回答哪一个研究问题？
- 如果删除该方法，哪一项判断将失去必要证据？
- 数据只显示相关，作者凭什么声称因果或机制？
- 研究内容之间的前后关系如何在方法和材料中体现？
- 项目周期内，团队能否取得并分析承诺的材料？

## 来源与等级

- H3 第 3 页说明研究设计及资料收集、分析、解释后回答问题；第 4 页强调多角度理解问题、求证并按结果修正，A。
- H1 第 6—10 页、H2 第 7—14 页呈现研究内容、方法、计划和目标的映射，归纳为 B。
- 具体核验字段和结论强度审查属于 C。

## 学科边界

经济学样本中的投入产出分析、一般均衡、计量模型和变量不作为通用建议。评审应从项目自身学科传统、问题类型、研究对象、证据规范和研究条件判断方法是否合适。
