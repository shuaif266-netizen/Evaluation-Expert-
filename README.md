# National Social Science Proposal Reviewer

This repository packages a reusable Codex skill for rigorous, evidence-led review of National Social Science Fund and other social-science research proposals.

## Installable skill

The repository root is the installable skill package: SKILL.md, references/, and assets/. Install the repository root with Codex skill-installer, then invoke $nssfc-proposal-reviewer. In the local project, the source skill lives at .codex/skills/nssfc-proposal-reviewer/.

The proposal-writing skill remains separate and is not merged into this reviewer role.

## Included project resources

- SKILL.md and references/: review workflow, rubric, logic-chain checks, failure patterns, source map, and expert-question bank.
- 02_方法论知识库/: traceable secondary notes with A/B/C evidence grades.
- 03_评审标准/: the reusable report template.
- 06_测试集/: benchmark criteria and a generalized calibration record.

## Review principles

Use the current call notice and application template supplied for each review. Separate academic severity (S/A/B/C) from compliance severity. Do not invent sources, policy claims, data, expert opinions, or funding outcomes.

## Source and privacy scope

This package contains distilled methods and reusable review rules. It does not include raw application forms, source PDFs or slide decks, individual review reports, temporary conversions, or personal information. Original materials and individualized reports remain in the user's local workspace. Keep each new application and its review report local unless the user explicitly chooses particular anonymized cases for publication.
