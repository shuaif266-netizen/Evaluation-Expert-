# 方法论知识库

本目录保存从匿名化方法材料中抽象出的项目申请书写作与研究设计检查方法，不保存原始申请书、课件、私人报告或个人信息。分发包可以独立使用，不依赖本地项目路径。

## 证据等级

- A：匿名化来源在可定位页明确表达的原则。
- B：多个材料的结构或做法可归纳出的稳定关系。
- C：本评审系统为诊断和测试提出的分析性推断。

A/B/C 表示开发方法来源的证据类型，不是问题严重度，也不是使用者每次评审必须援引的权威标准。它们是 Plugin 的 provenance 记录，不代表所有申请书都必须采用来源样本中的结构、概念或方法。来源定位、边界和迁移要求见 ../skills/nssfc-proposal-reviewer/references/expert-source-map.md。

## 条目

- 核心申报逻辑：对象、问题、章节功能与整体闭合。
- 选题与问题意识：从现实或学术情境形成可回答的问题。
- 立项依据与文献综述：由已有研究推出尚未解决的问题。
- 研究内容与方法匹配：任务、材料、方法和结论的对应。
- 创新与前期基础：知识增量和研究能力条件的核验。
- 高风险与适用边界：证据、外推和学科迁移风险。

申请书样本中具体的研究主题与学科专属方法不作为其他领域的模板。
