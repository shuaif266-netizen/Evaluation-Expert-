# Reviewer benchmark

本基准测试跨学科判断、证据边界和误判克制，不评价输出是否“挑出很多问题”。案例均为合成材料，不来自任何真实申请书。

## 每项核心能力的期望

- 逻辑链：明确指出现实/学术情境、理论张力、问题、任务、方法、证据和知识增量间是否能推出。
- 概念本体：标注核心概念的逻辑角色，并识别同一分类中是否混有对象、原因、机制、结果、价值或策略。
- 理论张力：查明是价值冲突、经验事实还是理论解释分歧；要求项目说明新增解释。
- 结论—证据匹配：按描述、关系、机制、因果/效果结论提高证据要求，不机械要求统一样本量。
- 学术/合规分轨：学术 S/A/B/C 与合规阻断/风险/提醒/不适用分别判断；纯手续学术等级为不适用。
- 框架形式主义：检查分类规则、穷尽、互斥、层级、经验材料、后续分析用途和维度必要性。
- 反向否证：提出有文本根据的最强反对意见，并检验申请是否回应；不为严格而造问题。
- 来源边界：区分“申请书没有证明”与“客观不存在”，不编造文献、政策、数据或专家观点。
- 误判克制：对设计与结论相称的合格案例明确说未发现 S/A 级问题。

## 案例索引

1. case01_core_question：热点叠加但学术问题未形成。
2. case02_concept_levels：分类混合多种逻辑角色。
3. case03_method_evidence：方法与因果、机制结论强度不匹配。
4. case04_false_innovation：创新标签缺少相对比较。
5. case05_good_proposal：设计与有限结论相称，测试是否过度挑错。
6. case06_compliance_vs_academic：手续阻断与学术风险并存但必须分轨。
7. case07_cross_discipline：历史与解释性研究，测试是否机械套用量化标准。

## 人工标注记录字段

案例 / 学科与范式 / 目标模式 / 发现与证据 / 漏判 / 误判 / 学术严重度 / 合规严重度 / 结论—证据匹配 / 概念层级 / 过度批评 / 是否符合期望。

单个案例只用于检验一个或少数能力，不得据此把案例中的学科内容变成通用规则。
