# 合成测试材料：良好申请书（不用于挑错）

本案例完全合成，不对应任何真实申请或个人。

项目类型：校级社会科学研究项目。学科：艺术教育。官方通知和模板未随测试材料提供。

题目：同伴引导式博物馆讲解中青年观众意义协商的过程研究。

学术问题：在两个博物馆教育项目的限定场景中，不同引导方式如何促成或限制青年观众在讨论中修正、扩展或坚持对展品的解释？

合成文献地图（仅为测试材料，不是可引用文献）：既有研究 A 主要解释参观参与因素；研究 B 通过访谈描述艺术学习动机；项目评估 C 主要统计活动参与情况。申请人据此提出一个有边界的缺口：现有材料未显示同伴讨论中意义如何随互动推进、改变或保持。

对象和范围：同一城市两个已有稳定课程的博物馆教育项目，一个以开放提问为主，一个以讲解提示卡为主；观察一个学期内每个项目 8 次活动。访谈 24 名青年参与者，每人活动后和学期结束各访谈一次；同时分析活动材料及匿名化讨论记录。

方法：先以“提出解释—回应他人—修正/扩展/坚持”为分析代码，按活动逐段重建互动序列；再在每个项目内分析反例，并比较两类引导方式下的序列差异。将课程材料、观察记录和两轮访谈互相核对。申请书将结论限制为对所选项目中互动过程的解释，不声称普遍因果效果。

可行性：两个项目已同意讨论入场安排；申请书说明将取得机构许可、监护/参与者同意并去标识讨论记录。

预期贡献：为“意义协商如何在同伴引导活动中发生”补充过程解释，并界定哪些观察支持或反驳该解释。测试材料没有声明某一方法普适，也没有提供真实官方条件。
