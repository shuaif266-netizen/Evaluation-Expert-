# Skill Activation Eval

本目录测试 Skill 是否应该触发，与 Skill 触发后的评审质量分开记录。案例是合成提示，不包含真实申请书。

人工或新版本 Codex 验证时，分别检查：

1. 主 Reviewer 是否在应触发的申请书评审请求中启动。
2. 普通论文润色、一般科研写作和非申请材料任务是否避免启动完整 Reviewer。
3. 材料不足时是否限制评审范围。
4. Reviewer 与 Calibration Skill 的任务边界是否清晰。

记录实际选择的 Skill、模式、输出范围、漏触发和误触发。没有可观察到 Skill 选择事件的客户端，标记“无法观测”，不得把文本结果猜测成选择日志。
