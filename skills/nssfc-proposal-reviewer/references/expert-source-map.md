# 匿名化方法来源索引

本文件仅为方法论二次提炼提供来源类型和定位代码。原始申请书、课件及任何个人信息均不随 Plugin 分发；使用者不需要原始文件才能运行 Reviewer。

## 来源代码

- H1：匿名化的社会科学项目申请书样本。只用于观察申请书章节如何连接，不用于证明该申请获得资助或代表普遍最佳实践。
- H2：匿名化的项目申报方法课件。可支持其明确讲授的选题、对象界定、栏目组织等观点。
- H3：匿名化的研究方法课件。可支持其明确讲授的研究设计、资料收集—分析—解释、求证和修正判断等观点。

页码或幻灯片号只用于本项目既有的来源审查记录。发布包不含源材料，亦不要求用户自行访问来源文件。

## A/B/C 证据边界

- A：对应来源在可定位页面明确表达。仅限该具体原则，不扩写成跨学科的统一规范。
- B：多个来源的结构可归纳出较稳定的写作关系。应写“从材料可归纳”，不冒充来源原话。
- C：Reviewer 自行提出的诊断工具、推理和示例。标明为系统分析，不归因于来源。

## 可迁移边界

1. 可复用的是问题—对象—内容—方法—证据之间的论证关系和可追问性。
2. 样本中的具体主题、理论、模型、数据、变量或政策结论不进入通用知识。
3. 研究设计标准须按本次项目的学科传统、问题类型、证据规范和官方规则判断。
4. 材料未显示某个申请的评审结果时，不推断其获批或质量等级。
5. 仅凭单一申请书样本不能建立跨学科、跨项目类型的普遍规律。

## 与知识文件的对应

方法论二次提炼位于 Plugin 根目录的 knowledge/。每份文件标注 A、B 或 C 的来源等级；来源不足时降低等级或不作断言。
