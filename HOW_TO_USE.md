# How to use the reviewer skill

Install this repository root as a Codex skill with skill-installer. Then provide the proposal and the official call notice for its application year, and ask for a strict peer review. The skill begins with a five-minute triage, then reviews academic structure, logic, methods, evidence, competitiveness, and compliance separately.

For example:

“请严格评审这份申请书。先做 5 分钟专家初审，再做完整结构、逻辑和竞争性评审。优先报告学术命门；另列制度合规阻断项。每个严重问题说明位置、依据、专家疑问、根因和修复方向。最后告诉我如果只能修改三个地方，最该改什么以及为什么。”

Keep application sources and individualized review reports in the local workspace unless you explicitly choose particular anonymized cases for publication.
