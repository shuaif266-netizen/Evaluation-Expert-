# 第一次盲测：Reviewer 校准记录

日期：2026 年 10 月 2 日  
盲测材料：一份 2025 年度校内科研项目申请书（原稿未随包发布）  
基线报告：本地模拟评审报告（未随 Skill 包发布）  
校准性质：规则层小幅更新；本轮不重新评审申请书，也不改写基线报告。

## 1. 第一次盲测暴露的问题

1. 基线报告把“后续项目目标 / 成果计划缺失”和“成员签名及单位字段缺失”都放入 S 级问题。前者影响项目与预先研究任务的匹配及竞争力；后者属于报送手续，不能与核心学术问题放在同一严重度池。
2. 报告发现了几组三分框架没有映射，但没有进一步判断这些概念分别是研究对象、伦理现象、机制、规范原则还是策略，也没有直接检验一组分类是否遵循同一原则。
3. “技术—人文”张力被当作可能的理论问题处理，但没有继续追问它是价值判断还是经验 / 理论解释分歧，也没有检验研究是否新增了解释。
4. 方法意见主要采用“是否列出样本量、对照组、指标”等清单。样本申请书确实提出问卷、机制研究和教学实验，要求这些信息有依据；Reviewer 仍须先判断申请人准备得出何种强度的结论，再确定所需证据，避免把论文级方法细节机械要求给描述性研究。
5. 框架分类和方法缺口找得较好，但没有单列“如果删去热点、政策意义和漂亮术语，剩下什么学术问题”的诊断结论，也没有把一个形式整齐的框架是否真参与后续分析作为固定检查项。

## 2. 保留的有效判断

- 从申报通知中提取了成果和后续高层次项目目标要求，并与申请书的目标、成果表逐项对照。
- 识别了研究现状缺口到核心问题之间的断点，以及伦理分类到问卷、案例和实验指标之间的映射缺口。
- 检查了跨章节一致性、研究内容—方法—证据关系和结论边界。
- 将“申请书未证明”与“客观上不存在”区分，未把团队能力不足写成已证事实。
- 对政策和事实表述作了来源核验，并指出适用范围或日期过度概括。
- 保留问题位置、依据、专家疑问、根因和修改方向的诊断格式；保留 A/B/C 对李宏材料来源等级的要求。
- 保留反向否证、高风险扫描和“先诊断根因、后给修改方向”的工作流。

## 3. 需要调整的判断

| 基线判断 / 做法 | 校准后做法 | 校准理由 |
|---|---|---|
| 签字缺失被作为 S 级问题，与项目学术成立性并列 | 标为“提交手续 / 合规阻断”；学术严重度不适用。若正式签字版已另行完成，标为已核实或不适用 | 这是明确的行政提交条件，不表示核心研究问题不成立 |
| 未写后续项目目标和硬性成果，直接列为 S 级 | 分开评估：项目匹配 / 学术竞争力按证据定 S/A/B；通知要求未满足时另标合规风险或合规阻断 | “文本未写明”不必然证明申请人实际不符合；需区分竞争力缺口与硬性违规 |
| 以缺少样本量、对照组等信息直接作为方法缺陷 | 先按描述、关系、机制、因果 / 效果结论分类，再判断研究设计需要哪些信息 | 方法要求应与预期结论强度匹配 |
| 发现多套框架称为分类不一致 | 逐个概念标注逻辑角色，检查分类原则、层级、映射和分析用途，再判断属于概念层级混杂、框架形式主义或可解释的多层结构 | 不因多套结构同时出现就自动判错 |
| 报告以 S/A 问题总体排序 | 学术核心风险优先；制度合规阻断项另列；B/C 问题置后 | 避免容易核实的手续问题压过学术命门 |

## 4. 新增规则

- 每个问题记录“问题性质”，并区分“学术严重度 S/A/B/C”和“合规严重度”。
- 增加概念本体审查：研究对象、现象、原因、条件、机制、中间过程、结果、价值判断、规范原则、治理策略。
- 增加理论矛盾深挖：判别价值冲突、经验事实和理论分歧；要求指出既有理论的解释边界、未解释现象及项目新增解释。
- 增加结论强度—证据强度映射：描述、关系、机制、因果 / 效果分别对应不同证据要求。
- 增加框架形式主义检查：分类原则、穷尽 / 互斥性、逻辑层级、经验支撑、对分析和结论的实际作用。
- 每次评审回答剥离政策意义、现实意义、热点和术语后，剩余的核心学术问题是什么；无法用 1—2 句话说清时作为重大警报。
- 调整完整评审报告顺序：学术命门、研究设计风险、创新与竞争力、制度合规阻断项、B/C 级问题。

## 6. 防止对单个案例过拟合

- 把两条 S 级意见的重新分类当作校准触发点，不把申请书主题、艺术学概念、特定申报表字段写成普遍规则。
- 新增规则采用跨学科角色定义和结论强度分类；每次均要求按当年通知、学科规范和材料范围判断适用性。
- 对“合规阻断”要求引用具体条款或表格要求，并标注条件；不能仅凭材料空白断定申请人客观不合格。
- 保留反证条件和“申请书尚未证明”措辞；不因一份案例增加固定的样本量、方法清单或理论框架模板。

## 7. 第二次盲测重点

选择一份学科与研究范式不同的匿名申请书，最好同时存在一个手续 / 硬性条件问题和一个真正的学术问题。重点观察 Reviewer 能否：

1. 把签字、资格、时限等事项放入合规轨道，并将学术核心风险排在前面；
2. 识别漂亮分类是否混合对象、原因、机制、结果和策略；
3. 判断“效率—公平”或“技术—人文”是理论解释问题还是规范性取舍；
4. 按描述、关系、机制、因果 / 效果分别评价证据强度；
5. 剥离热点和政策背景后，用 1—2 句话复述核心学术问题。

下一次测试应记录旧规则可能造成的误伤与新规则带来的漏判；不以第二份案例中出现同样主题作为成功标准。

### 自检结论

- 合规手续不再占用学术 S/A 名额；混合问题可分别记录学术影响和合规状态。
- 纯手续问题的学术严重度为“不适用”；合规阻断须引用明确规则并注明版本条件。
- 方法核查按结论强度调整，不再把固定样本量或单一方法细节设为所有项目的门槛。
- 本轮没有重审申请书、改写盲审报告、创建新案例或运行第二次盲测。下一次评估应使用跨学科材料检验新增区分能力。
