# Reviewer Skill 基准评估方案

## 双轨标注

每个问题分别记录：问题性质（学术成立性 / 学术竞争力 / 研究设计 / 证据 / 制度合规 / 提交手续 / 表达技术）、学术严重度（S / A / B / C / 不适用）和合规严重度（合规阻断 / 合规风险 / 提交提醒 / 不适用）。对每条方法意见记录结论强度（描述 / 关系 / 机制 / 因果或效果 / 规范）及证据是否相称。对框架性问题记录概念角色和分类层级。
## 当前状态

截至 2026 年 10 月，已经完成一次盲测，并形成第一次盲测校准记录。原申请书和逐案评审报告未作为通用案例存入本测试集；当前没有脱敏后可复用的完整案例。
## 评估目标

判断系统能否优先发现影响立项判断的问题，并为每项重要判断提供文本位置和论据；同时控制漏判、误判、无依据批评和过度关注措辞的问题。

## 建议覆盖的案例类型

- 问题意识不足：热点或现象描述无法推出学术问题。
- 研究内容并列堆砌：任务互不依赖或与核心问题关系不清。
- 标签式伪创新：创新点未给出相对已有研究的知识增量。
- 题目大、内容小：题目、样本、研究内容和结论边界失配。
- 方法无法回答问题：方法、材料与目标结论不匹配。
- 跨章节冲突：题目、摘要、综述缺口、方法或基础发生漂移。
- 制度手续与学术问题并存：检查 Reviewer 是否将硬性签字 / 资格 / 输出要求单列，并仍能优先识别学术命门。
- 形式整齐但层级混杂的框架：检查 Reviewer 是否识别对象、机制、价值判断和策略混列。
- 结论强度不一的申请书：检查 Reviewer 是否根据描述、机制或因果结论调整证据要求。

以上是待收集的案例类型，不是已完成的测试案例。

## 每个案例的记录字段

案例编号 / 学科 / 年份 / 材料版本 / 官方评审标准 / 匿名状态 / 原稿位置 / 初次评审意见 / 专家判断 / 证据充分性 / 问题性质 / 学术严重度合理性 / 合规严重度合理性 / 结论—证据匹配 / 概念层级判断 / 漏判 / 误判 / 过度批评 / 修订结果 / Skill 修改建议 / 复测结论。

## 人工复核方式

优先使用申请书对应的真实专家意见；没有真实评审意见时，由两名熟悉该学科的人工评审者独立标注。把“未被申请书证明”与“客观上不成立”分开编码。案例不足时不报告虚假精度或总体准确率。

第二次盲测建议使用与首次不同学科和研究范式的匿名申请书，提供当年官方要求，并尽量让材料同时出现学术缺陷与提交合规事项、多层概念框架以及描述 / 机制 / 因果强度不同的结论主张。重点验证 Reviewer 能否分轨判级，而不是复现首次案例的结论。
