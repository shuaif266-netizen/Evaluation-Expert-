# 常见失效模式

下列模式用于发现问题，不构成自动判错清单。等级须按其对核心问题和设计的实际影响判断。

## 选题与问题意识

- **热点替代问题**：背景提到热点、政策或技术变化，却未说明需要解释的现象和未知关系。
- **对象过宽、问题过窄**：题目覆盖大领域，研究任务只分析一个有限局部，边界没有解释。
- **对象变化冒充理论问题**：更换地区、群体、技术或材料，却未显示解释机制或知识增量变化。
- **现实重要性直接跳到学术价值**：政策重要或社会影响大，但尚无理论矛盾、可检验问题或研究路径。

## 文献与立项依据

- **文献点名式罗列**：逐篇报告而不比较概念、方法、发现和边界。
- **人为制造空白**：以“鲜有研究 / 尚无研究”代替系统检索和有边界的比较。
- **缺口与方案脱节**：综述指出问题 A，项目内容实际研究 B。
- **政策口号代替学术论证**：有政策文本但没有解释政策目标如何转化为可研究问题。

## 概念、理论与研究问题

- **核心概念不可操作**：反复使用关键术语，却没有定义、边界或观察方式。
- **概念层级混杂**：把研究对象、现象、原因、机制、结果、价值判断、规范原则或治理策略并列成同一套分类，且未说明层级关系。
- **理论矛盾只在措辞上存在**：列举“技术—人文”“效率—公平”等张力，却没有说明它是价值取舍、经验事实还是理论解释分歧。
- **现实矛盾尚未转化为理论问题**：背景张力写得鲜明，但没有指出现有解释的边界、待解释现象及本项目新增的解释。
- **问题、任务与目标混淆**：章节标题是活动安排或预期成果，无法说明要回答什么。
- **预设结论**：论证把预期方向写成已证事实，未设置相反结果或替代解释。

## 内容、方法与证据

- **内容并列堆砌**：多个研究模块主题相关，但前后不提供必要接口，任意增删也不影响核心问题。
- **方法名词清单**：罗列访谈、案例、调查、模型等名称，缺少材料、程序、分析单位和推论边界。
- **结论—证据强度失配**：描述、关系、机制、因果 / 效果或规范结论所需证据各不相同；若材料只支持较弱结论，申请书却声称更强结论，需指出缺失的推理或识别环节。
- **方法—问题错配**：所选方法无法识别题目或目标声称的过程、变化、因果关系或价值判断。
- **可行性靠承诺**：关键数据、样本、场域、伦理权限或团队能力只作保证，没有落实方案。
- **难点停留在工作量**：写数据多、时间紧、任务复杂，却没有指出真正的知识识别难题。

## 创新、基础与竞争性

- **标签式创新**：把新视角、新方法、新模式列为标签，未说明相对已有研究新增何种可检验认识。
- **“首次 / 填补空白”无依据**：没有可复查的检索边界和文献比较。
- **基础以数量替代匹配**：成果很多，却看不出如何支持本项目最关键的理论、方法、材料或实施任务。
- **成果远超设计**：高数量、广应用或多层次成果承诺没有对应研究内容、周期和证据。
- **只做可行性、不做竞争性**：项目可以完成，但与同类研究相比没有清晰区分度。
## 框架与分类

- **框架形式主义**：三维框架、层级模型或“主体—技术—场景”等结构形式整齐，却未说明分类原则、各维边界、经验依据及其在分析中的作用。
- **多套框架无接口**：同一项目分别用对象分类、风险分类和策略层级，但没有说明如何从一类推导到另一类。
- **虚假的穷尽 / 互斥**：分类看似完整，却存在遗漏、交叉，或分类标准在各项之间变化。

## 合规问题与学术问题的区分

- **合规事项挤占学术诊断**：把签字、日期、字段、格式等作为最严重学术问题排序，导致核心研究问题、概念或证据缺陷被压后。
- **手续缺失被推定为资格事实**：材料中缺少证明时，直接断言申请人不符合资格。应区分“当前版本未证明”“待核验”和“明确违反规定”。
- **合规问题未引用规则**：没有提供适用通知或模板条款，却把个人偏好写成硬性要求。

## 作者盲区与跨章节冲突

- 作者熟悉主题，默认评审也知道省略的推理。
- 专业名词很多，但问题无法被一句话复述。
- 研究内容多，被误认为研究深入。
- “别人没做过”被误认为有创新。
- 方法数量多，被误认为设计完善。
- 题目、摘要、正文、创新和成果对核心概念的用法不一致。
